EI 6.1 인스턴스는 Carbon SOAP 관리 웹서비스(NDataSourceAdmin)로 데이터소스를 등록/조회/수정/삭제합니다 — 이름을 클릭하면 수정, "관리" 열에서 삭제할 수 있습니다.
데이터소스명은 서버에서 바로 검색되어 빠르고, JNDI 이름/설명은 전체 목록을 받아와 하나씩 조회하며 걸러내므로 데이터소스 개수가 많으면 다소 시간이 걸릴 수 있습니다.
이름타입접속 상태관리
여러 인스턴스에서 접속 테스트
데이터소스 등록명(예: SST0002_MSSQL)이 아니라 JNDI 이름(예: jdbc/SST0002, "_" 앞부분만)을 입력하세요. 여러 JNDI 이름을 ,로 구분해 입력하면 선택한 인스턴스마다 전부 테스트합니다.

레지스트리 탐색
폴더를 클릭하면 펼쳐지고, 파일을 클릭하면 내용을 조회합니다. 입력하는 즉시 이미 펼쳐둔 폴더 안에서 걸러서 보여줍니다(위치를 아는데 한 폴더에 파일이 많을 때) — 어디 있는지 모르면 Enter나 "검색"으로 레지스트리 전체를 찾습니다(느릴 수 있음).
레지스트리 리소스
예: registry/config/jdbc/DeleteInsert.yaml — 저장 시 존재 여부를 자동 판단해 생성(POST) 또는 수정(PUT)합니다. 조회는 슬래시 없이 파일명만 입력해도 인스턴스에 설정된 JDBC 레지스트리 경로를 붙여 자동으로 찾습니다 (예: DeleteInsert.yaml).
